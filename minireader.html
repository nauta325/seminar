2부 · 복사해서 인터넷에 올리기

1코드 복사하기 (Fork)

강사 템플릿 저장소를 열어 내 것으로 복사합니다. (폰은 QR 스캔)

🔗 github.com/nauta325/mini-reader
  1. 위 주소 열기 → 오른쪽 위 Fork → Create fork
  2. 주소가 github.com/(내아이디)/mini-reader 로 바뀌면 성공
⚠️ GitHub에 처음 로그인하면 "Home · Ask anything · Create project…" 같은 화면이 떠요. 여기선 아무것도 누르지 마세요. 위 버튼(또는 QR)으로 바로 이동해서 Fork만 하면 돼요.
💡 Fork 버튼이 없으면 → GitHub 로그인부터.
2데이터베이스 만들기 (Supabase)
  1. supabase.com → New project · Region Northeast Asia (Seoul) · DB 비밀번호 메모
  2. 내 저장소에서 sql/mini-setup.sql 열기 → Raw → 전체 복사
  3. Supabase SQL Editor → New query → 붙여넣기 → Run → Success
  4. (선택) sql/mini-seed-demo.sql 도 Run → 데모 채워짐
⚠️ SQL은 반드시 끝까지 Run! 중간에 멈추면 나중에 녹음 저장이 안 돼요.
💡 빨간 에러 → 복사가 잘린 것 → Raw로 전체 다시 복사해 Run.
3주소·키 복사하기
  1. Project URL: Settings → Data API → 복사 (https://xxxx.supabase.co)
  2. service_role 키: Settings → API Keys → service_role Reveal → 복사
💡 키는 꼭 service_role! anon이면 저장·로그인이 안 돼요. 이 키는 비밀번호급 — 남에게 X.
4인터넷에 올리기 (Vercel) ⭐가장 중요
⚠️ 환경변수를 "Deploy 누르기 전에" 넣으세요! (뒤에 넣으면 다시 배포해야 해서 헷갈려요)
  1. vercel.com → Add New → Project → 내 mini-reader Import
  2. Deploy 전에 Environment Variables 펼치고 3개 추가:
이름값
SUPABASE_URL3번의 Project URL
SUPABASE_SERVICE_KEY3번의 service_role 키
ANTHROPIC_API_KEY내 Anthropic 키 (있으면)

그다음 Deploy → 1~2분 → Congratulations 🎉 → Visit

5API 키 발급 없는 사람만
  1. console.anthropic.com → Billing → Buy credits ($5)
  2. API Keys → Create Key → sk-ant-… 복사(한 번만 보임!)
  3. Vercel ANTHROPIC_API_KEY 에 넣고 → Redeploy
💡 카드가 안 되면 → 크롬 언어를 English로 바꾸고 다시 시도(잘 됩니다).

3부 · 백지에서 내 프로젝트

🚀복사 말고, 처음부터 만들기

흐름은 2부와 똑같아요.

  1. 기획 5분 — 앱 이름 / 한 줄 설명 / 오늘의 첫 목표(이것만 되면 성공)
  2. 새 GitHub 저장소 만들기 — 왼쪽 위 Create repository (Public + README). ⚠️ "Create project / Create your first code project"는 다른 것이에요!
  3. Claude Code 새 세션 → 연결 → 기획 붙여넣고 "mini-reader처럼 단순하게, 가장 작게 만들어줘"

  5. 새 Vercel — Deploy 전에 환경변수 (같은 함정)

🎯 제일 흔한 실패 = 처음부터 크게. "이것 하나만 되면 성공" 으로 작게 시작!

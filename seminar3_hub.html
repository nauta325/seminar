코드 & 도구

실습 원본 · 바이브 코딩 도구

📦 원서 시스템 템플릿 & 도구

실습은 이 템플릿 저장소를 "Use this template"로 복사해서 시작해요. 바꾸고 싶을 땐 Claude Code에게 말로 시키면 됩니다.

📦 원서 시스템 템플릿 (Use this template로 시작) 열기 → 🤖 Claude Code (크롬에서 말로 코딩) 열기 → ✨ Claude 구독 (claude.ai) 열기 →

시작 방법

  1. 템플릿 저장소 열고 Use this template → Create a new repository
  2. 주소가 내 아이디/mini-reader 로 바뀌면 내 것
  3. Claude Code에서 내 저장소 연결 → 한국어로 말해서 수정
🔑 안전 — 키(비밀값)는 전부 Vercel 환경변수에만 넣어요. 코드·HTML엔 절대 안 들어가서, 남이 소스를 봐도 안전합니다.

질문 & 도움받기

막히면 · 1:1

💬 카톡 질문방

설치하다 막히면 화면 캡처 + 어디서 막혔는지 한 줄만 남겨주세요. 세미나 후 1주일간 1:1 답변도 갑니다.

카톡 질문방 입장하기 입장 →
고쳤는데 사이트가 그대로예요
① Vercel에서 Redeploy 됐는지 ② 강력 새로고침(Ctrl/Cmd+Shift+R) ③ 지금 보는 주소가 내 프로젝트가 맞는지 확인하세요. 대부분 이 셋 중 하나예요.
루트 주소에서 404가 떠요
앱은 /mini/ 아래에 있어요. 주소 끝에 /mini/를 붙여서 여세요.
녹음이 저장이 안 돼요
Supabase에 recordings 저장 공간이 없어서예요. sql/mini-setup.sql을 끝까지 다시 Run 하면 녹음 버킷까지 생성됩니다.
저장·로그인이 안 돼요
Vercel에 넣은 키가 anon일 수 있어요. Supabase에서 service_role 키(Reveal)로 교체하고 Redeploy 하세요.
API 키 발급 때 카드가 안 돼요
크롬 언어를 English로 바꾸고 다시 시도하면 통과되는 경우가 많아요. 크레딧이 0이면 Billing → Buy credits로 충전(약 $5)하세요.
